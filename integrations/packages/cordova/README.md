# CMP Cordova

Nhánh tùy chọn theo WBS. Cài plugin vào host Cordova, đưa example/index.html vào
www và build native app. Hai nút mở native consent hoặc màn đăng ký native có
consent nhúng. Cần Maven mobile-bridge 0.1.0 và pod CMPMobileBridge 0.1.0.
Host cần minSdk phù hợp thư viện, quyền Internet và cấu hình release HTTPS.
Mã nguồn chưa được xác nhận bằng Cordova CLI và thiết bị; không coi là release.
